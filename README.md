# Apresentação: Entendendo Resultados de Modelos

## Descrição
Esta apresentação foi desenvolvida para a disciplina de Mudanças Climáticas, com foco na interpretação de resultados de Modelos de Distribuição de Espécies (SDM). O conteúdo aborda conceitos básicos sobre como avaliar, entender e aplicar modelos preditivos na ecologia e conservação.

## Conteúdo
A apresentação inclui os seguintes tópicos:
- Conceitos básicos de avaliação de modelos
- Métricas importantes: acurácia, precisão, sensibilidade (recall), AUC
- Matriz de confusão e tipos de erros
- Curvas de resposta e sua interpretação
- Importância de variáveis
- Aplicações práticas no mundo real

## Como utilizar
Esta apresentação utiliza o framework reveal.js. Para utilizá-la:

1. Abra o arquivo `analise_modelo.html` em um navegador web.
2. Navegue pelos slides usando as setas do teclado ou clicando nas bordas dos slides.
3. Pressione a tecla 'Esc' para ver uma visão geral de todos os slides.

## Pré-requisitos
- Navegador web moderno (Chrome, Firefox, Edge, Safari)
- As imagens devem estar na pasta `imagens/` (certifique-se de que esta pasta existe com todas as imagens necessárias)

## Personalização
Você pode personalizar esta apresentação editando o arquivo HTML. É possível:
- Modificar o conteúdo dos slides
- Adicionar ou remover slides
- Alterar estilos e formatação
- Substituir imagens na pasta `imagens/`

## Referências
- Os conceitos apresentados são baseados na literatura científica sobre modelagem ecológica e distribuição de espécies.
- O design da apresentação utiliza [reveal.js](https://revealjs.com/), uma estrutura HTML para criação de apresentações.
